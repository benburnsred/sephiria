# Sephiria HM60 Builds

A single-page, icon-based view of the community "HM60 builds" guide for Sephiria: 16 builds with talent, fruit skewer, wishing fountain, miracle, artifact priority, combo order, notes and copyable preset codes.

Open `index.html` in a browser (or enable GitHub Pages on this repo).

Source: the "HM60 builds" Google Sheet (last updated 29-09-26). Build credits are noted on the relevant cards.
